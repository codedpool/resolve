# S0.2 vendor findings

Date: 24 Nov 2026. Sources: https://console.groq.com/docs/reasoning, https://console.groq.com/docs/structured-outputs, https://console.groq.com/docs/speech-to-text, https://docs.rumik.ai/streaming.md, plus the live calls in `docs/results/s0.2-smoke.md`.

## How to select the mode

- Qwen instruct (non-thinking): `reasoning_effort` of `none`. `default` also returns no reasoning tokens on Groq. `low`, `medium`, and `high` enable thinking.
- gpt-oss: `reasoning_effort` of `low`, `medium`, or `high`. There is no `none`. Reasoning arrives in the `reasoning` field. `include_reasoning: false` hides it. `reasoning_format` does not apply to gpt-oss.

## Strict schema

Qwen 3.8 strict mode accepts a FactCandidate object whose absent value is `certainty=not_stated` and `value=""`. Every field was required and `additionalProperties` was false.

## Prompt Guard

The 86M model returns a probability string. Higher means more like an injection. Benign samples were near 0. Injection samples were near 1, in English and Hindi.

## Rumik streaming

- Call `POST https://silk-api.rumik.ai/v1/tts/ws-connect` with `model`, `text`, and `language`. Omitting `text` is a 422. The token lasts 300 seconds.
- Keep the socket open. A new `{"text": ...}` frame interrupts the current one (`cancelled`, `reason=interrupt`). `{"type":"cancel"}` stops with `reason=cancel`.
- `muga` also sends a `queued` frame. The voices list does not offer hindi for `muga`, but a hindi language value was accepted.
- `credits_used` was 0 on these short lines. Balance, rate, and expiry were not in `GET /v1/agent/limits`.
